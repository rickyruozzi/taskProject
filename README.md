Task project è un comodo gestore di task basato su un interfaccia web (creata tramite il famework react con JS) e un server back-end basato invece sulla libreria fastAPI di Python. 
Il progetto utilizza come database di riferimento MongoDb, se si desiderasse implementare il progetto anche basandosi su altri DBMS (eventualmente anche non Collection-Document based) il sottoscritto sarà 
felice di valutare eventuali Pull requests.
